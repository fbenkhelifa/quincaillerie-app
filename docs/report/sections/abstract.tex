\noindent
This report presents a comprehensive technical overview of the \textbf{Quincaillerie Application}, a full-featured Hardware Store Management System designed to address the operational challenges faced by small to medium-sized retail hardware stores. The application provides an integrated solution for inventory management, point-of-sale operations, purchase order processing, intelligent replenishment recommendations, and business analytics.

\vspace{0.3cm}

\noindent
Built using modern web technologies—\textbf{Laravel 12} (PHP 8.2) for the backend, \textbf{React 18} with \textbf{Inertia.js v2} for the frontend, and \textbf{Material-UI v6} for the user interface—the system demonstrates professional software engineering practices including domain-driven design, role-based access control, automated background jobs, and comprehensive testing strategies.

\vspace{0.3cm}

\noindent
The application features a bilingual interface (French and Arabic with RTL support), dark/light theme switching, responsive design for mobile and tablet devices, and a professional POS mode optimized for barcode scanners. Key modules include product catalog management, bill generation with PDF export, supplier management, purchase order workflows, automated reorder suggestions using statistical forecasting, anomaly detection, and real-time analytics dashboards.

\vspace{0.3cm}

\noindent
This document provides detailed insights into the system architecture, database design, core business workflows, security implementations, performance optimization strategies, and user experience design decisions. It also includes a demonstration script and outlines future enhancements to guide continued development.

\vspace{0.3cm}
