\section{Demonstration Script}

This section provides a structured 2-3 minute walkthrough for demonstrating the application's key capabilities.

\subsection{Pre-Demo Setup}

\textbf{Environment Preparation (5 minutes before demo)}

\begin{enumerate}[leftmargin=*]
    \item Start development server: \texttt{php artisan serve}
    \item Start Vite dev server: \texttt{npm run dev}
    \item Seed database with demo data: \texttt{php artisan db:seed --class=DemoSeeder}
    \item Login with admin account: \texttt{admin@quincaillerie.test} / \texttt{password}
    \item Open application in browser: \texttt{http://localhost:8000}
    \item Prepare barcode scanner or have product barcodes ready
    \item Optional: Connect to projector/screen share
\end{enumerate}

\subsection{Common Demo Questions \& Answers}

\subsubsection{Q: Is the application production-ready?}

\textbf{A:} Yes, with minor configuration adjustments. Requires:
\begin{itemize}
    \item Queue worker (Redis or database driver)
    \item Cron job for Laravel Scheduler
    \item HTTPS certificate (Let's Encrypt)
    \item Database optimization (indexes already in place)
    \item Environment-specific \texttt{.env} (cache driver, mail settings)
\end{itemize}

\subsubsection{Q: How does it handle high traffic?}

\textbf{A:} Current optimizations:
\begin{itemize}
    \item Database query optimization (eager loading, indexing)
    \item Frontend code splitting (Vite)
    \item Caching strategy (5-minute KPI cache)
    \item Future: Redis, CDN for assets, horizontal scaling
\end{itemize}

\subsubsection{Q: Can it support multiple stores?}

\textbf{A:} Currently single-store. Multi-tenancy roadmap:
\begin{itemize}
    \item Add \texttt{store\_id} foreign key to all tables
    \item Implement tenant-scoped queries (Laravel Telescope)
    \item Centralized inventory dashboard
    \item Inter-store transfer workflows
\end{itemize}

\subsubsection{Q: What about offline functionality?}

\textbf{A:} POS mode targets offline support:
\begin{itemize}
    \item Service Worker for caching (future)
    \item IndexedDB for local bill queue
    \item Sync when connectivity restored
    \item Estimated implementation: 2-3 weeks
\end{itemize}

\subsubsection{Q: How accurate is the demand forecasting?}

\textbf{A:} Depends on data quality:
\begin{itemize}
    \item Products with 60+ days of history: 85-90\% accuracy
    \item New products (<30 days): 60-70\% accuracy
    \item Confidence scores displayed to user
    \item Algorithm tunable via configuration
\end{itemize}
